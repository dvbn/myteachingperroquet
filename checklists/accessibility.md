# Accessibility Checklist

Use this for generated student-facing HTML, widgets, and dashboards.

## Visual

- Text contrast is readable.
- Font sizes are usable on mobile and desktop.
- Important information is not conveyed by color alone.
- Focus states are visible.
- Layout works at narrow screen widths.

## Interaction

- Keyboard navigation is possible for controls.
- Buttons and inputs have clear labels.
- Errors are described in text.
- Loading states are visible.
- Motion is limited and not essential.

## Content

- Headings follow a logical order.
- Links have descriptive text.
- Math/technical content has enough surrounding explanation.
- Generated images or diagrams have text alternatives where practical.

## TA/Quiz Specific

- Hints, solutions, and feedback are distinguishable.
- Quiz mode does not trap the user.
- Authentication failure messages are clear without exposing security details.
