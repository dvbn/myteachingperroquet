# User Guide

Course: `<course_id>`

## What This Bundle Contains

- Verified source corpus and handoff packages.
- Quizbank JSON files, if generated.
- TA ingestion outputs, if built.
- Verification, source, privacy, cost, and deployment notes.

## How To Use It

1. Review `SOURCE_NOTES.md` to understand what material was used.
2. Review `ASSESSMENT_STYLE_AUDIT.md` to understand why the quizbank uses its
   selected question types and solution style.
3. Review `VERIFICATION.md` to understand what was tested and what still needs human review.
4. If a quizbank exists, inspect a sample of exercises before showing students.
5. If a TA deployment exists, test chat and quiz mode before sharing the URL.

## What Students Should Know

The TA is grounded in approved course material, but it can still make mistakes.
Students should use it as practice support, not as an authoritative replacement
for lectures, readings, or instructor guidance.

## Instructor Editing

Most outputs are Markdown or JSON. You can ask an agent to make targeted
changes, but review the changes before re-approving the next phase.
