# Demo content attribution

The chapters in `lectures/` are excerpts from:

**Three Men in a Boat (To Say Nothing of the Dog)** by Jerome K. Jerome, first
published 1889. Public domain worldwide.

Source text: [Project Gutenberg eBook #308](https://www.gutenberg.org/ebooks/308).
Project Gutenberg trademark headers and footers have been removed; the
underlying narrative text is unmodified and bears no copyright.

This is sample content shipped only to make the pipeline runnable on a fresh
clone. Replace the `lectures/` directory with your own material before
deploying. The format expected by the pipeline is documented in `README.md`.
